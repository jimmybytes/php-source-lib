## Learning Resources
> Valuable communities, blogs, websites, articles, books, videos, and other resources related to PHP

- **PHP Websites**
    - [PHP The Right Way](https://phptherightway.com/) - A quick reference guide for PHP best practices (still highly recommended in 2025)
    - [Awesome PHP](https://github.com/ziadoz/awesome-php) - A curated list of PHP libraries, resources, and shiny things (regularly updated)
    - [PHP FIG](https://www.php-fig.org/) - PHP Framework Interop Group
        - [PSR Standards](https://www.php-fig.org/psr/)
    - [Laravel News](https://laravel-news.com/) - Official Laravel blog and news
    - [SitePoint PHP](https://www.sitepoint.com/php/) - Tutorials and articles
    - [PHP Classes](https://www.phpclasses.org/blog/) - PHP scripts, book reviews, and resources

- **Recommended Blogs (2025)**
    - [Benjamincrozat.com](https://benjamincrozat.com/best-php-blogs) - Curated list of top PHP blogs
    - Laravel Daily (by Povilas Korop) - In-depth Laravel tutorials and videos
    - Blogs by Matthias Noback, Ash Allen, and others highlighted in 2025 roundups

- **Recommended Articles**
    - [Clean Code PHP](https://github.com/jupeter/clean-code-php) - PHP coding standards
    - [Learn Regex the Easy Way](https://github.com/ziishaned/learn-regex/blob/master/translations/README-cn.md) - Regular expressions guide

## Frameworks
> Web development frameworks (Top in 2025)

- [Laravel](https://laravel.com/) - The most popular full-stack framework
- [Symfony](https://symfony.com/) - Component-based, enterprise-ready
- [Hyperf](https://hyperf.io/) - High-performance coroutine framework based on Swoole (rising in 2025)
- [Spiral](https://spiral.dev/) - Modern high-performance framework
- [Laminas](https://getlaminas.org/) (formerly Zend)
- [Yii](https://www.yiiframework.com/)
- [CakePHP](https://cakephp.org/)
- [CodeIgniter](https://codeigniter.com/) - Lightweight and beginner-friendly

**Asynchronous/High-Performance**
- [Swoole](https://www.swoole.com/) - Coroutine-based engine
- [Hyperf](https://hyperf.io/) - Enterprise-grade microservices framework
- Laravel Octane - For running Laravel with Swoole/RoadRunner
